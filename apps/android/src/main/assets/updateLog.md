**2026/11/15 · 1.0.0**
- 统一管理本地文件、群晖 NAS 及 WebDAV / SMB / FTP / SFTP 网络位置
- 支持目录浏览、搜索、筛选、排序与多选批量操作，并提供分类入口
- 支持跨端上传下载、同端复制移动，任务可暂停、恢复与取消
- 音视频在线流式播放，无需完整下载即可定位进度
- 支持图片与文档预览、压缩包压缩与解压、回收站与收藏管理
- 群晖支持 IP / 域名 / QuickConnect 登录及官方收藏、回收站
- 打开方式可指定默认应用，未知类型按后缀识别
- 提供深浅色外观、预置配色、自定义颜色与动态取色
- 应用图标可随主题色变化，桌面图标按色相分档切换
- 下拉刷新仅作用于当前页；网络切换后自动重建通道并重载目录
- 连接失败区分离线、飞行模式、地址端口错误、认证失败与服务端异常
- 统一时间格式与分隔线样式，分类排序采用 4×2 网格
- 连接凭据加密存储于本机，文件直连传输不经过第三方服务器
